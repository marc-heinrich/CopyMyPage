# Address catalogue provenance

The `regions.*.json` files contain first-level country subdivisions generated
from Unicode CLDR 48.2 `common/supplemental/subdivisions.xml` and the matching
locale files in `common/subdivisions`.

Source: https://github.com/unicode-org/cldr/tree/release-48-2
